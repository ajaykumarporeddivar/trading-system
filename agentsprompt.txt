## BASE CLASS CONTRACT

File: arena/base_agent.py

class BaseAgent(ABC):
  __init__(name, strategy_name, order_db_path):
    self.name = name
    self.strategy_name = strategy_name
    self.order_db_path = order_db_path
    self.virtual_capital = INITIAL_BALANCE     # 10,000 USDT paper
    self.peak_capital = INITIAL_BALANCE
    self.daily_start_capital = INITIAL_BALANCE
    self.open_positions: Dict[str, Dict] = {}
    self.closed_positions: Dict[str, Dict] = {}
    self._load_state()

  Abstract method (each agent implements this):
    generate_signal(market_data: Dict) -> Optional[Dict]

  Provided methods (fully implement these in base):
    submit_paper_order(signal, current_price) -> Dict
      - Position sizing: (virtual_capital * RISK_PER_TRADE) / stop_distance
        where stop_distance = current_price * signal["stop_loss_pct"]
      - quantity = risk_amount / stop_distance
      - position_value = quantity * current_price
      - If position_value > virtual_capital * MAX_EXPOSURE:
          CAP position (don't skip): quantity = max_position_value / current_price
          Log: "Capped position size for SYMBOL to  (30% exposure)"
      - Check: agent has no open position in same symbol already
      - Check: len(open_positions) < MAX_POSITIONS
      - Compute stop_loss and take_profit prices from signal pcts
      - Save order to JSON with status "open"
      - Print: [AGENT] PAPER BUY/SELL SYMBOL @ price | qty | conf% | reason

    close_position(order_id, exit_price, reason) -> Dict
      - Calc PnL: BUY -> (exit - entry) * qty, SELL -> (entry - exit) * qty
      - pnl_pct = pnl / position_value * 100
      - outcome = WIN / LOSS / BREAKEVEN
      - Update virtual_capital += pnl
      - Update peak_capital = max(peak_capital, virtual_capital)
      - Save updated record
      - Export closed trade to training_data.jsonl
      - Print: [AGENT] WIN/LOSS SYMBOL @ exit | PnL:  (y%) | reason

    check_exits(current_prices: Dict[str, float])
      - For each open position:
        BUY:  close if price <= stop_loss OR price >= take_profit
        SELL: close if price >= stop_loss OR price <= take_profit
      - Pass reason "stop_loss" or "take_profit"

    check_risk_limits() -> bool
      - daily_pnl = virtual_capital - daily_start_capital
      - drawdown = (peak_capital - virtual_capital) / peak_capital
      - Return False (halt) if daily_pnl <= -(INITIAL_BALANCE * DAILY_LOSS_CAP)
      - Return False (halt) if drawdown >= MAX_DRAWDOWN
      - Return True (ok to trade)

    get_performance() -> Dict
      Returns: {agent, strategy, total_trades, wins, losses, win_rate,
                total_pnl, avg_pnl, best_trade, worst_trade,
                virtual_capital, open_positions (count), peak_capital}

    reset_daily_capital()
      - Set daily_start_capital = virtual_capital

    _load_state()    - load from JSON on init (includes closed_positions)
    _save_state()    - persist to JSON (includes closed_positions)
    _append_training_row(order) - append JSONL row to TRAINING_EXPORT

  Order record format:
  {
    "order_id":      str (uuid4 first 8 chars),
    "agent":         str,
    "strategy":      str,
    "symbol":        str,
    "side":          "BUY" | "SELL",
    "entry_price":   float,
    "quantity":      float,
    "position_value": float,
    "stop_loss":     float,
    "take_profit":   float,
    "stop_loss_pct": float,
    "take_profit_pct": float,
    "confidence":    int,
    "reason":        str,
    "status":        "open" | "closed",
    "opened_at":     ISO timestamp,
    "closed_at":     ISO timestamp | null,
    "exit_price":    float | null,
    "pnl":           float | null,
    "pnl_pct":       float | null,
    "outcome":       "WIN" | "LOSS" | "BREAKEVEN" | null,
    "close_reason":  str | null,
    "features":      dict (copy of full indicators at entry — for ML)
  }

  JSON file structure (orders/AGENTNAME_orders.json):
  {
    "agent": str,
    "strategy": str,
    "virtual_capital": float,
    "peak_capital": float,
    "daily_start_capital": float,
    "open_positions": { order_id: order_record },
    "closed_positions": { order_id: order_record },
    "last_updated": ISO timestamp
  }

## THE 6 AGENTS — COMPLETE STRATEGY SPECIFICATIONS

Signal format returned by generate_signal():
{
  "symbol": str,
  "side": "BUY" | "SELL",
  "confidence": int (0-100),
  "reason": str  (pipe-separated list of conditions met),
  "stop_loss_pct": float,
  "take_profit_pct": float,
  "features": dict  (copy of indicators)
}

Rules for ALL generate_signal() implementations:
  - Guard every indicator: if any(v is None for v in [...]): return None
  - Build confidence additively — each condition = explicit point value
  - Only return signal if confidence >= MIN_CONFIDENCE (65)
  - Cap confidence at 95
  - reason = " | ".join(list of conditions that fired)
  - Never invent data — if indicator is None, skip that condition silently

### arena/arena_runner.py
The main orchestrator loop. Uses async/await (DataAgent methods are async).
Runs every POLL_INTERVAL seconds via asyncio.sleep().

Each cycle:
  1. Instantiate DataAgent. Fetch market data for all SYMBOLS via get_all_indicators().
     Also call get_market_overview() to get current prices.
  2. Build market_data dict for each symbol combining indicators + price + change_pct.
  3. For each agent, for each symbol:
       a. Call agent.check_risk_limits() — skip agent entirely if False (halted)
       b. Call agent.check_exits(current_prices) — close any triggered positions
       c. Call agent.generate_signal(market_data)
       d. If signal returned and confidence >= MIN_CONFIDENCE:
            call agent.submit_paper_order(signal, current_price)
  4. After all agents processed: call leaderboard.print_leaderboard()
  5. Call training_export.export_performance_csv()
  6. Sleep POLL_INTERVAL seconds
  7. Reset daily_start_capital at midnight (check date change each cycle)

Handle exceptions per-agent — one agent crashing must not stop the loop.
Log each cycle start/end with timestamp and cycle number.

  Returns None if no agent has 10+ trades yet.
